2. 添加以下域名：

   - **downloadFile合法域名**: `https://phtoto-test-1302910967.cos.ap-chongqing.myqcloud.com`

### 步骤 2: 本地预览
1. 打开微信开发者工具
2. 导入项目，选择 `miniprogram` 目录
3. 点击「详情」→「本地设置」→ 勾选「不校验合法域名」
4. 预览各页面功能是否正常

### 步骤 3: 真机调试
1. 点击工具栏「预览」按钮
2. 用手机微信扫码
3. 测试以下功能：
   - ✓ 作品集图片加载
   - ✓ 分类筛选
   - ✓ 图片预览
   - ✓ 摄影师信息展示
   - ✓ 预约表单提交
   - ✓ TabBar 切换

### 步骤 4: 上传代码
1. 点击工具栏「上传」按钮
2. 填写版本号（如 `1.0.0`）和项目备注
3. 上传成功后登录微信公众平台

### 步骤 5: 提交审核
1. 登录微信公众平台
2. 进入「版本管理」
3. 找到刚上传的版本，点击「提交审核」
4. 填写审核信息：
   - **服务类目**: 生活服务 > 摄影/扩印
   - **标签**: 摄影、古风、预约
5. 等待审核（通常 1-7 个工作日）

### 步骤 6: 发布上线
审核通过后，在「版本管理」中点击「发布」即可上线

## ⚠️ 注意事项

1. **域名配置**: 必须先配置合法域名才能正式发布
2. **图片格式**: COS 中的图片建议使用 JPG/PNG，大小控制在 500KB 以内
3. **隐私协议**: 如果收集用户信息，需要添加隐私政策
4. **后端接口**: 当前预约功能是模拟提交，实际需要对接后端 API

## 🔧 常见问题

**Q: 图片加载不出来？**
A: 检查 COS 域名是否配置为合法域名，本地调试时勾选「不校验合法域名」

**Q: TabBar 不显示？**
A: 确保 `custom-tab-bar` 目录存在且文件完整

**Q: 预约提交后没反应？**
A: 当前是模拟提交，需要对接云函数或后端 API 保存数据

**Q: 审核被拒？**
A: 常见原因：缺少隐私政策、服务类目不匹配、功能不完整
