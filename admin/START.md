# 后台快速开始

## 1. 启动后台

```bash
cd admin
npm install
npm start
```

浏览器打开：

```text
http://localhost:8080
```

## 2. 摄影师怎么配置

1. 点“店铺资料”，填写头像、微信、电话、门店地址。
2. 点“首页内容”，填写首页标题、介绍和微信分享卡片。
3. 点“页面装修”，选择商业皮肤和首页结构，设置 1–4 列作品、2–5 个底部入口、常用图标与门店称呼，并调整页面模块、顺序和咨询字段。
4. 点“预约选项”，维护客户可选的拍摄风格。
5. 点“服务内容”，维护套餐、档期、评价、服务流程和常见问题。
6. 回到作品管理区，新增分类、作品集并上传照片。

## 3. 保存规则

- 修改内容后点击“保存并更新小程序”。
- 新增分类和作品集只需要填写名称，系统会自动处理编号。
- 下架分类、作品集或照片不会删除文件，只是不在小程序展示。
- 误建分类、作品集或误传照片均可点击垃圾桶永久删除，操作无法恢复。
- 如果先在 COS 控制台删除了照片，请到“云端设置”点击“同步已删除照片”。
- 需要恢复时，在后台点“恢复”。
- 点“云端”保存后，会自动生成小程序本地客户配置 `miniprogram/config/client.config.js`。
- `client.config.js` 是客户私有配置，不要提交到 Git。
- 当前保存会直接更新当前 COS；预发布、版本回滚和一键安装暂未启用。

## 4. 技术人员配置

`.env` 里需要配置客户自己的云端存储信息：

```env
COS_SECRET_ID=YOUR_COS_SECRET_ID
COS_SECRET_KEY=YOUR_COS_SECRET_KEY
COS_BUCKET=YOUR_COS_BUCKET
COS_REGION=YOUR_COS_REGION
PORT=8080
```

摄影师日常不要修改 `.env`。
