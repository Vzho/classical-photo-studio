# 摄影师后台使用说明

这个后台用来维护小程序展示内容：作品、套餐、评价、预约信息、店铺资料和整体风格。

摄影师日常不需要编辑代码，也不需要手写配置文件。打开后台后，按页面按钮填写内容，最后点击“保存并更新小程序”。

## 最常用的 5 件事

1. **上传作品**
   - 左侧选择作品分类，例如“分类 A”“分类 B”“分类 C”。
   - 右侧选择作品集，点击上传按钮。
   - 照片上传完成后，小程序会显示这个作品集。

2. **新增作品分类或作品集**
   - 点击“新增分类”或“新增作品集”。
   - 只需要填写名称，系统会自动处理编号。
   - 不需要填写拼音 ID。

3. **下架内容**
   - 分类、作品集、照片都支持“下架”。
   - 下架后小程序前台不再展示，但照片文件不会被删除。

4. **永久删除误传内容**
   - 作品分类名称旁的垃圾桶按钮会删除整个分类及其内部作品集。
   - 单张照片右上角的垃圾桶按钮会同时删除后台记录和对应 COS 文件。
   - 作品集右上角的垃圾桶按钮会删除整个作品集，并删除不再被其他作品集使用的照片。
   - 永久删除无法恢复，操作前会再次确认。
   - 如果已经在 COS 控制台手动删除照片，可在“云端设置”中点击“同步已删除照片”，清理后台残留记录。
   - 点“恢复”可以重新展示。

4. **编辑套餐、评价、常见问题**
   - 点击顶部“服务内容”。
   - 按表单填写内容。
   - 高级配置默认折叠，普通使用不用打开。

5. **保存到小程序**
   - 修改后点击“保存并更新小程序”。
   - 保存成功后，小程序会读取最新内容。

## 顶部按钮说明

- **店铺资料**：摄影师姓名、头像、微信、电话、门店地址。
- **首页内容**：首页标题、标签、介绍文案，以及微信分享标题和 5:4 分享封面。
- **页面装修**：先选“经典作品站”或“暗色品牌画廊”整站结构，再调整皮肤、文字和入口。右侧会直接使用当前 COS 客片预览。暗色品牌画廊包含沉浸首页、独立作品目录、通栏作品详情和暗色简介页；可调整搜索、分类位置、两列/三列图片、标签及按钮文字。经典作品站继续支持 4 种首页结构和 5 种作品排列。底部可从首页/作品、作品目录、简介、套餐、咨询、门店中启用并排序 2–5 个入口。
- **预约选项**：咨询页里的心仪风格选项。
- **服务内容**：套餐价格、客户评价、服务流程、常见问题、右下角快捷入口。
- **云端设置**：技术人员配置云端存储时使用，摄影师日常不用修改。
- **重新加载**：重新读取当前内容。

## 页面装修怎么用

1. 先选择整站结构。“经典作品站”适合同时展示作品和服务；“暗色品牌画廊”适合强调品牌封面和图片浏览。右侧会立即预览，此时还没有写入云端。
2. 再选择最接近店铺气质的皮肤。暗色品牌画廊可展开“品牌画廊文字与排列”，调整作品目录标题、搜索、分类位置、列数和标签；经典作品站可在“页面内容”选择杂志封面、高定目录、影像画廊或门店转化。
3. 按需要选择错落图文、瀑布流、整齐卡片、横向滑动或大小图混排，再设置每行 1–4 个作品、标题/分类/描述和照片留白；四列会自动使用纯图片。
4. 在“顾客入口”中启用 2–5 个底部入口并调整顺序，再填写门店常用称呼，例如把“摄影师”改成“造型师”。
5. 按页面切换作品首页、简介、咨询、套餐列表、套餐详情、作品详情和咨询结果；用“移出页面”和“添加模块”控制内容，再用上下箭头排序。移出不会删除原内容。
6. 模块标题、补充说明和可用的操作文字可以直接改；预约咨询里的客户填写项目还可以调整名称、提示、顺序和必填状态。
7. 点击右侧预览中的任意模块，可以直接跳到左侧对应设置。选错时点击“恢复打开前的样式”，皮肤、首页结构和模块顺序都会恢复；确认后点击“保存并更新小程序”，配置才会同步到当前 COS。

当前版本保存后直接更新线上配置，暂未提供预发布、版本回滚和一键安装。

## 安全说明

- “下架”只是让小程序不展示，照片仍然保留，可以恢复。
- “永久删除”支持分类、作品集和照片，会删除后台配置和对应云端照片，无法恢复。
- 看到“高级配置”时，不确定就不要修改。
- 每次修改后记得点击保存按钮。

## 本地启动

```bash
cd admin
npm install
npm start
```

打开：

```text
http://localhost:8080
```

云端密钥、存储桶和 AppID 由技术人员在后台“云端设置”中配置。摄影师只负责后台内容维护。

后台“云端设置”保存后，会自动生成 `miniprogram/config/client.config.js` 和 `miniprogram/project.private.config.json`。两个文件都是客户本机私有配置，不要提交到 Git；源码仓库只保留通用模板。
