# 📊 云裳影像 - Web 管理后台

简易的 Web 管理界面，用于管理作品主题、系列和照片。

---

## 🚀 快速开始

### 1. 配置 COS 密钥

编辑 `app.js` 文件，填入你的腾讯云 COS 配置：

```javascript
const CONFIG = {
  cos: {
    SecretId: 'YOUR_SECRET_ID',      // 替换
    SecretKey: 'YOUR_SECRET_KEY',    // 替换
    Bucket: 'phtoto-test-1302910967',
    Region: 'ap-chongqing',
    BaseUrl: 'https://phtoto-test-1302910967.cos.ap-chongqing.myqcloud.com'
  }
}
```

**获取密钥：**
1. 登录腾讯云控制台
2. 访问：https://console.cloud.tencent.com/cam/capi
3. 创建或查看 API 密钥

### 2. 引入 COS SDK（可选）

如果需要直接上传/删除 COS 文件，在 `index.html` 中引入：

```html
<script src="https://cdn.jsdelivr.net/npm/cos-js-sdk-v5/dist/cos-js-sdk-v5.min.js"></script>
<script src="cos-helper.js"></script>
```

### 3. 启动本地服务器

由于浏览器安全限制，需要通过 HTTP 服务器访问：

**方法一：使用 Python**
```bash
# Python 3
python -m http.server 8080

# Python 2
python -m SimpleHTTPServer 8080
```

**方法二：使用 Node.js**
```bash
npx http-server -p 8080
```

**方法三：使用 VS Code**
安装 Live Server 插件，右键 `index.html` → Open with Live Server

### 4. 访问管理后台

打开浏览器访问：http://localhost:8080/admin/

## 🔧 当前限制

### 1. 配置文件保存
浏览器无法直接写入本地文件，所以：
- 修改后会自动下载 `portfolio-config.json`
- 需要手动替换到 `miniprogram/data/` 目录

### 2. COS 文件操作
默认版本不包含 COS SDK，照片操作是模拟的：
- 上传照片：只更新配置，不实际上传
- 删除照片：只更新配置，不实际删除

**启用 COS 功能：**
1. 在 `index.html` 中引入 COS SDK
2. 配置 SecretId 和 SecretKey
3. 取消 `app.js` 中 COS 相关代码的注释

## 📝 使用流程

### 添加新系列

1. **选择主题**：点击左侧主题列表
2. **添加系列**：点击右上角"+ 添加系列"
3. **填写信息**：
   - 系列ID：拼音，如 `shengtang`
   - 系列标题：中文，如 `盛唐遗韵`
   - 点赞数：默认 100
4. **上传照片**：点击系列卡片中的"+"或"📤"
5. **选择文件**：拖拽或点击选择照片
6. **确认上传**：点击"上传"按钮
7. **下载配置**：自动下载更新后的配置文件
8. **替换文件**：将下载的文件替换到 `miniprogram/data/portfolio-config.json`

### 删除照片

1. 鼠标悬停在照片上
2. 点击右上角的"×"按钮
3. 确认删除
4. 下载并替换配置文件

### 删除系列

1. 点击系列卡片右上角的"🗑️"按钮
2. 确认删除
3. 下载并替换配置文件

## ⚠️ 注意事项

### 1. 密钥安全
- **不要**将包含密钥的代码提交到 Git
- **不要**在生产环境中暴露密钥
- 建议使用临时密钥或后端代理

### 2. 文件命名
- 照片文件名格式：`主题ID-系列ID-序号.jpg`
- 例如：`qingleng-shuanghua-1.jpg`
- 保持命名规范，便于管理

### 3. 配置同步
- 每次修改后都要下载配置文件
- 手动替换到小程序目录
- 在微信开发者工具中重新编译

### 4. 浏览器兼容性
- 推荐使用 Chrome、Edge、Firefox
- 需要支持 ES6+ 语法
- 需要支持 File API

## 🐛 故障排查

**Q: 页面打不开？**
A: 确保使用 HTTP 服务器访问，不要直接双击 HTML 文件

**Q: 配置文件加载失败？**
A: 检查 `configPath` 路径是否正确，确保文件存在

**Q: 照片不显示？**
A: 
1. 检查 COS 域名配置是否正确
2. 检查照片文件名是否匹配
3. 检查 COS 文件权限是否为公有读

**Q: 上传照片没反应？**
A: 
1. 检查是否引入了 COS SDK
2. 检查密钥配置是否正确
3. 查看浏览器控制台错误信息
