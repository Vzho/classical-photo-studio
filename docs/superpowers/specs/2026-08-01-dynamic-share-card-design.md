# 微信分享卡片动态配置设计

日期：2026-08-01

状态：已确认设计，待实现

## 目标

让摄影师在 CMS 中直接维护微信好友分享卡片的标题和封面，不接触 JSON，也不需要修改小程序源码。首页使用全局分享标题，内容页自动附加当前内容名称；云端分享图不可用时仍必须显示本地兜底图。

## 当前问题

- 多个页面分别硬编码“摄影作品合集”，后台修改品牌名称不会同步更新分享标题。
- 首页分享图固定引用 `banner/main-banner.jpg`，当前客户 COS 中该对象不存在，微信因此显示默认灰色预览。
- 分享逻辑分散在各页面，容易出现页面之间标题和图片规则不一致。
- 微信分享卡片顶部的小程序账号名称和图标由微信公众平台控制，不属于本功能的可配置范围。

## 已确认方案

采用“全局配置 + 页面上下文自动组合”的方式。摄影师只维护一套全局分享设置，各页面通过公共分享模块生成最终标题和图片。

### CMS 字段

在“首页展示”管理界面增加“微信分享卡片”区域：

- 分享标题：单行输入框，默认值为“妆造作品合集”。
- 分享封面：上传、预览和替换，接受 JPG 或 PNG。
- 保存时与现有作品配置一起同步到 COS。

后台不显示配置字段名、JSON 或 COS 对象路径。图片建议比例为 5:4，上传控件使用 5:4 预览框展示，实际文件保持 JPG 或 PNG 格式，不在浏览器内执行二次裁切。

内部配置结构：

```json
{
  "share": {
    "title": "妆造作品合集",
    "imagePath": "share/share-cover-1785580800000.jpg"
  }
}
```

`imagePath` 以实际上传结果为准，不依赖固定文件名，避免 COS 缓存导致替换后仍显示旧图。

## 标题规则

- 作品集首页：`妆造作品合集`
- 具体作品集：`{作品名称}｜妆造作品合集`
- 摄影师简介：`妆造师介绍｜妆造作品合集`
- 套餐列表：`拍摄套餐｜妆造作品合集`
- 套餐详情：`{套餐名称}｜妆造作品合集`
- 预约咨询：`预约咨询｜妆造作品合集`

全局标题来自 CMS。页面前缀由页面类型或当前内容自动生成，不要求摄影师逐页填写。成功页不增加分享入口，避免把用户咨询结果作为公开分享内容。

旧配置没有 `share` 字段时，按以下顺序确定全局标题：

1. `share.title`
2. `theme.brandName`
3. `homeBanner.logoText`
4. 内置默认值“妆造作品合集”

## 图片规则

分享给好友的图片必须是 JPG 或 PNG，并按微信 5:4 展示。

- 具体作品集：优先使用该作品集第一张可见照片的原图地址，不使用 WebP 缩略图。
- 其他可分享页面：使用 CMS 配置的全局分享封面。
- 未配置全局分享封面：使用首页第一张“首页精选”作品图。
- 云端图片缺失、下载失败或格式不支持：使用代码包内的 5:4 JPG 兜底封面。

分享前由公共模块解析候选图片。需要下载网络图片时，使用 `onShareAppMessage` 支持的 Promise，并在微信允许的三秒内返回本地临时文件；超时直接返回代码包兜底图，不阻塞分享。

## 组件与职责

### 配置读取

在现有 COS 配置类型中增加 `ShareContent`。各页面现有的数据加载函数在同一次 `portfolio-config.json` 请求中返回分享配置，不能为分享再单独请求一次配置。

### 公共分享模块

新增一个独立分享工具，负责：

- 根据页面类型生成标题。
- 组合跳转路径和必要查询参数。
- 按候选优先级解析分享图片。
- 验证图片扩展名，只接受 JPG/JPEG/PNG。
- 下载网络图片并缓存临时路径。
- 网络失败时返回代码包兜底图。

页面自身只提供页面类型、内容名称、跳转路径和可选作品首图，不再拼接品牌文案。

### CMS 上传

复用现有内容图片上传流程并增加 `share` 目录支持，但服务端必须限制该目录只接受 JPEG/PNG。上传成功后返回 COS 相对路径，CMS 将其写入 `share.imagePath`。上传或保存失败时保留旧配置，不清空当前有效封面。

## 数据流

1. 摄影师在 CMS 填写分享标题并上传封面。
2. 后台将封面上传到 COS 的 `share/` 目录。
3. 后台把标题和相对图片路径写入 `config/portfolio-config.json`。
4. 小程序页面加载现有云端配置，同时取得分享设置。
5. 用户发起分享时，公共分享模块组合页面标题并选择分享图。
6. 微信生成带标题、图片和目标页面路径的好友分享卡片。

## 错误处理与兼容

- 配置读取失败：沿用本地配置兜底，并使用内置分享标题和封面。
- 标题为空：CMS 不允许保存空标题；运行时仍应用标题回退链。
- 分享封面 404：尝试首页精选图，再回退代码包图片。
- 作品首图被下架：使用第一张仍可见照片，不分享已下架图片。
- 私有或签名即将过期的 COS 地址：先下载为本地临时文件，不把短时签名 URL 直接作为最终分享图。
- 历史配置：不要求手工迁移 JSON，CMS 打开时自动补充默认分享配置。

## 验证标准

- CMS 能编辑“妆造作品合集”并上传、预览、替换分享封面。
- 保存后 COS 配置包含 `share.title` 和 `share.imagePath`。
- 首页分享显示 CMS 标题和全局封面。
- 作品集详情分享显示“作品名称｜全局标题”，图片为第一张可见作品图。
- 简介、套餐和咨询页面使用约定的自动标题与全局封面。
- 删除或阻断云端分享图后，分享卡片仍显示本地兜底图，不出现灰色默认预览。
- 修改 CMS 标题后重新进入页面，所有可分享页面同步使用新标题。
- 分享路径能正确打开目标页面，作品集和套餐详情参数不丢失。
- 静态检查不再允许页面 `onShareAppMessage` 中出现硬编码“摄影作品合集”。
